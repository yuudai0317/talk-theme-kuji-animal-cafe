# トークテーマくじ｜動物好きのカフェ会

動物好きが集まるカフェ会で使う、トークテーマの抽選アプリです。
100問のテーマをシャッフルし、1問ずつカードをめくる演出で表示します。

テーマは**ペットの話が中心**です。「うちの子」「あるある」「世話と暮らし」の
68問が一緒に暮らしている動物まわりの話題で、残りは入口をつくる導入と、
終盤に置く想像・交流のテーマです。

## 特徴

- **単一HTMLファイル**。外部ライブラリも通信も使いません。
- **データを保存しません**。状態はすべてメモリ上で扱い、ページを閉じると消えます。
- スマートフォンでの利用を前提にしたレイアウトと文字サイズです。

## 使い方

1. 「くじを引く」（またはカードをタップ）でテーマを1問引きます。
2. 答えにくいテーマは「この話題はパス」で末尾に戻せます。
3. 「これまでのテーマ」から、引いた順に見返せます。

### 主催者メニュー

画面下部の「主催者メニューは長押し」を**2秒長押し**すると開きます。

- カテゴリ絞り込み（ウォームアップ／うちの子／あるある／世話と暮らし／もしも／つながる）
- 番号を指定して呼び出す（1〜100）
- 演出の長さ（短め1.5秒／標準3.8秒／じっくり5.0秒）
- 文字を大きく表示
- 最初からやり直す

すべて未選択のときは、序盤ほど易しいテーマが出る自動制御で進みます。

## テーマの差し替え

`index.html` 内の `THEMES` 配列を書き換えてください。

| キー | 内容 |
| --- | --- |
| `n` | 通し番号（1〜100） |
| `c` | カテゴリ（下表の `A`〜`F`） |
| `t` | 難易度（`1`=誰でも即答 / `2`=経験談 / `3`=想像・偏愛） |
| `q` | テーマ本文 |

### カテゴリの内訳

| | カテゴリ | 問数 | 内容 |
| --- | --- | ---: | --- |
| `A` | ウォームアップ | 14 | 全員が一言で答えられる導入 |
| `B` | うちの子 | 28 | 名前、性格、クセなど、その子自身の話 |
| `C` | あるある | 24 | 一緒に暮らすと起きる出来事 |
| `D` | 世話と暮らし | 16 | ごはん、健康、お金、お出かけ |
| `E` | もしも | 12 | うちの子を軸にした想像の話 |
| `F` | つながる | 6 | 締めと、参加者どうしの交流 |

カテゴリを1つも選んでいないときは、`t`（難易度）にもとづき、最初の3問は
`1` のみ、8問目までは `1`〜`2` から出す自動制御が働きます。

## デプロイ

Netlify に接続し、publish directory を `.`（リポジトリ直下）に設定します。
ビルドコマンドは不要です。設定は `netlify.toml` に含まれています。
